# Antibiotic Awareness website

This finished static website works by opening `index.html` in any modern browser.

## Publish it free for students

1. Create a free GitHub account if you do not already have one.
2. Create a new public repository, for example `antibiotic-awareness`.
3. Upload the three files in this folder: `index.html`, `styles.css`, and `app.js`.
4. In the repository, choose **Settings** → **Pages**.
5. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. GitHub will provide a public website link. Share that link with students.

The site is educational only and should not be used for diagnosis or individual treatment advice.
